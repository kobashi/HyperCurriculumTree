# 2026年度 科目別担当者一覧

2026年度前期・後期の情報メディア学科時間割から、同じ科目名のクラスをまとめた担当者一覧。

担当教員のうち、大学公式サイトで写真を確認できた人は[顔写真一覧](2026-faculty-portraits.md)を参照。

資料: [前期時間割](../2026前期情報メディア学科-1.pdf)（全4ページ）、[後期時間割](../2026-2media4.pdf)（全4ページ）。どちらも2022～2026年度入学者用。

- 同一科目の複数クラスで担当者が異なる場合は、時間割の記載順に ` / ` で併記。共同担当の `、`、氏名の一部が姓のみの表記、`他` は資料の記載を保持。
- `—` はその学期の時間割に科目の掲載がないこと、`記載なし` は科目の掲載はあるが担当者欄が空欄であることを示す。
- 学籍番号指定、受講条件、曜日・時限はこの一覧には含めない。実際の履修先は時間割原本で確認する。
- 就職ガイダンス、就活スキルパワーアップ講座、公務員試験対策講座は科目ではないため除外。
